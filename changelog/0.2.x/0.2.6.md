# 0.2.6 — 2026-10-07

## Changed

- **Argument repair** accepts safe integers supplied for string fields, including `representationId`; argument rejection hints identify field paths (mcp-ts-core 0.13.9).
- **Modern HTTP calls** using protocol 2026-07-28 require `MCP-Protocol-Version`; a missing header is rejected with HTTP 400 / `-32020` (SDK 2.1, adopted in mcp-ts-core 0.13.9).
- **Tool failures** carry `data.requestId` and a trailing request ID in their text (mcp-ts-core 0.13.10).
- **Maintenance** refreshes Bun metadata to 1.4.2, bundle exclusions, CodeQL language categories, environment ignore rules, development tooling and framework guidance. Configuration docs clarify stateless defaults, read-only registration, and opt-in failed-call logging.

## Fixed

- **MCP Registry launch metadata** uses `npx` without npm-script arguments and explicitly selects HTTP for the Streamable HTTP entry.
- **Native macOS tests** use a file-scoped 30-second default deadline instead of the five-second unit default; explicit per-test deadlines, assertions, and private-pasteboard isolation remain unchanged ([#52](https://github.com/cyanheads/clipboard-mcp-server/issues/52)).
