# 0.2.2 — 2026-09-19

## Changed

- **HTTP session configuration** now sets the server default through `createApp({ sessionMode: 'stateless' })`. HTTP still defaults to stateless; an explicit MCP_SESSION_MODE value overrides that default.
- **Client configuration parsing** now treats whole-value unsubstituted placeholders as unset, so `CLIPBOARD_READ_ONLY` uses its default when an install host leaves it untouched; blank values retain that behavior.
- **MCP tool calls** inherit case-style input-key aliases, invalid-argument recovery guidance, and error text that includes declared reason and retryability terms from `@cyanheads/mcp-ts-core` ^0.13.6.
- **Build, package, and bundle checks** validate client configuration wiring, keep agent documentation out of MCPB bundles, and support either root or `config/` build tsconfig locations.
- **Agent workflow skills** move to `framework-skills/` so plugin hosts do not auto-load development guidance.
- **Plugin metadata and issue intake** now declare schema and author details, assign new reports to `cyanheads`, and provide a private security-reporting path.
- **Runtime requirements** now require Bun 1.4.0 or later.

## Fixed

- **HTML plain-text fallbacks** preserve quoted angle brackets and literal comparison text, decode supported references once, discard declarations and comments, and omit `script`/`style` raw text. ([#34](https://github.com/cyanheads/clipboard-mcp-server/issues/34))
- **`clipboard_inspect`, `clipboard_read`, and `clipboard_write`** no longer advertise the dead `clipboard_unavailable` error contract; their input and success schemas are unchanged.
