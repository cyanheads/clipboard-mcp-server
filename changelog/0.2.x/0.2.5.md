# 0.2.5 — 2026-09-24

This release changes only the test harness; the published server runtime is unchanged.

## Fixed

- **`startServer()` test harness** starts the server with `MCP_HTTP_PORT=0` and reaches it through the URL on the `listening at` log line, so a run no longer draws fetch-blocked port 3659 or collides with a port in use. ([#49](https://github.com/cyanheads/clipboard-mcp-server/issues/49))
