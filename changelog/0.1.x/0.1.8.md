# 0.1.8 — 2026-08-30

## Changed

- **`clipboard_write`** now documents that HTML plain-text fallbacks are available on macOS and Windows only; Linux publishes `text/html` alone (#9, #10, #11, #12, #13, #14).

## Fixed

- **Clipboard backend selection** uses the Windows-native `where.exe` probe for PowerShell (#9, #10, #11, #12, #13, #14).
- **Linux text reads** fall back through standard clipboard text targets, and inspection only advertises PNG as an image format (#9, #10, #11, #12, #13, #14).
- **Windows clipboard reads** preserve text, HTML, and RTF bytes exactly, distinguish absent from empty text, and capture image dimensions before disposal (#9, #10, #11, #12, #13, #14).

## Dependencies

- `@biomejs/biome` ^2.5.9 → ^2.5.11; `@types/node` ^26.2.0 → ^26.4.0; `js-yaml` ^5.3.0 → ^5.4.1.
