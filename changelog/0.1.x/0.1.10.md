# 0.1.10 — 2026-09-08

## Added

- **`clipboard_write`** now returns an optional `previousContent` — the plain text on the clipboard immediately before the write, via a pre-read through `ClipboardService.write()`. Absent when the clipboard was empty, held no text representation, or its prior text exceeded the read size limit; never blocks the write itself. ([#28](https://github.com/cyanheads/clipboard-mcp-server/issues/28))

## Changed

- **`clipboard_read`**'s `format()` fences `text`/`html`/`rtf` payloads with `MarkdownBuilder.codeBlock()` instead of interpolating them directly, so clipboard bytes can't control how `content[]` renders. `structuredContent.content` is unchanged. ([#22](https://github.com/cyanheads/clipboard-mcp-server/issues/22))
- **`clipboard_read`**'s handler attaches image reads to `content[]` via `ctx.content.image()` on both the `auto` and explicit `format: "image"` paths, so a client reading only `content[]` gets the same image a `structuredContent` client gets. ([#6](https://github.com/cyanheads/clipboard-mcp-server/issues/6))

## Fixed

- **`stripHtmlTags()`** decodes decimal (`&#169;`) and hexadecimal (`&#xA9;`/`&#XA9;`) numeric character references, reaching the macOS and Windows HTML plain-text fallback. Astral code points produce a well-formed surrogate pair; out-of-range and lone-surrogate references pass through unchanged. ([#25](https://github.com/cyanheads/clipboard-mcp-server/issues/25))
