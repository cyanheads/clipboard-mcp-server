# 0.1.5 — 2026-06-11

## Added

- **`.claude-plugin/` and `.codex-plugin/` manifests** — Claude Code and Codex plugin metadata for marketplace install.
- **`manifest.json` `repository`, `homepage`, `license`** — populated for the MCPB bundle.

## Changed

- **`@cyanheads/mcp-ts-core` `^0.9.9` → `^0.10.6`** — framework upgrade.
- **Server identity** — `createApp()` sets explicit `name`/`title` of `clipboard-mcp-server` so every surface displays the hyphenated repo name rather than the scoped package name.
- **`clipboard_read` / `clipboard_write` `content_too_large`** — error contract code changed from `InvalidParams` to `ValidationError`.
- **`bundle` script** — runs `scripts/clean-mcpb.ts` after `mcpb pack` to strip dependency-shipped agent docs (`skills/`, `.claude/`, `.agents/`) from the `.mcpb`.
- **MCP client config keys in README** — `clipboard` → `clipboard-mcp-server`, matching the server identity.
- **Project skills re-synced** to the framework's `^0.10.x` set; `migrate-mcp-ts-template` removed upstream.
- **Dependency bumps:**
  - `@biomejs/biome` ^2.4.15 → ^2.4.16
  - `@types/node` ^25.9.1 → ^25.9.3
  - `vitest` ^4.1.7 → ^4.1.8
