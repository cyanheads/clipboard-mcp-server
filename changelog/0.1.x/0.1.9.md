# 0.1.9 — 2026-09-08

## Added

- **`CLIPBOARD_READ_ONLY`** env var serves the clipboard read-only: `clipboard_write` is not registered — absent from `tools/list` and uncallable, though still shown disabled on the manifest and landing page (#27).

## Changed

- **`MCP_HTTP_MAX_BODY_BYTES`** now defaults to 7 MiB (framework default is 1 MiB) so a full-size `clipboard_write` survives worst-case JSON escaping (#19).
- **`MCP_SESSION_MODE`** now defaults to `stateless` — this server keeps no per-session state (#18).
- **Server instructions** no longer claim macOS-only support (#8).

## Removed

- **Docker** section dropped from the README — the server requires direct host OS clipboard access and doesn't run in a container (#4).
- **8 unwired maintenance scripts** vendored in from mcp-ts-core, plus their now-unused `clipboardy`, `execa`, and `js-yaml` devDependencies (#17).

## Fixed

- **0.1.7 changelog** corrected its vitest bump from `^4.1.10` to the `^4.1.11` package.json actually shipped (#16).
