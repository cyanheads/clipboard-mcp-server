# 0.1.7 — 2026-08-21

## Changed

- **Framework `@cyanheads/mcp-ts-core` `^0.10.6` → `^0.12.3`** — adopts MCP SDK v2 (`@modelcontextprotocol/server` ^2.0.0); every endpoint serves protocol revision 2026-07-28 alongside 2025-era clients.
- **Advertised schemas are JSON Schema 2020-12** (was draft-07), and the declared `outputSchema` includes the error envelope — clients that validate `structuredContent` without checking `isError` stop rejecting error results with `-32602`.
- **Strict root inputs** — an undeclared argument key is rejected by name instead of stripped (`additionalProperties: false`); input-validation failures read as flat `path: message` sentences.
- **Supply-chain install guard** — `bunfig.toml` holds freshly published versions for 3 days (`@cyanheads/mcp-ts-core` exempted) and runs the Socket security scanner on every install.
- **Toolchain** — TypeScript 7, Biome 2.5.9, `@types/node` 26, `packageManager` pinned to Bun 1.4.0.
- **Community health files** — `.github/SECURITY.md` disclosure policy, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`; `FUNDING.yml` trimmed to active entries.
