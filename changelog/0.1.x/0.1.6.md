# 0.1.6 — 2026-06-15

## Added

- **`createApp()` `instructions`** — server-level usage guidance: the `clipboard_*` tools read, write, and inspect a single live clipboard slot (no history), `clipboard_inspect` surfaces available formats, `clipboard_read` defaults to `auto`, images return as base64 PNG.

## Changed

- **Plugin display identity unscoped** — `.claude-plugin/plugin.json` (`name`, `mcpServers` key), `.codex-plugin/plugin.json` (`name`, `interface.displayName`), and `.codex-plugin/mcp.json` (server key) now use the bare `clipboard-mcp-server` instead of `@cyanheads/clipboard-mcp-server`, so agent-facing surfaces show the repo name. Install `args` stay scoped (`@cyanheads/clipboard-mcp-server`) — the published npm package is unchanged.
- **Dependency bumps:**
  - `@biomejs/biome` ^2.4.16 → ^2.5.0
  - `vitest` ^4.1.8 → ^4.1.9
