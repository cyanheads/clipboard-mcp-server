# 0.3.0 — 2026-10-28

## Added

- **`clipboard-guide` agent skill** — served at `skill://clipboard-guide/SKILL.md` (with the `skill://{+path}` template) through `createApp({ skills })`, so `resources/list` now lists it; it also ships under `skills/` in the npm package and the `.mcpb` bundle, and the server `instructions` point to it.
- **Agent Plugins root manifests** — `plugin.json` and `mcp.json` at the repository root, following Agent Plugins 1.0.0; `plugin.json` tracks `package.json`'s version.

## Changed

- **Server `instructions`** say `clipboard_read` with format `"auto"` returns an image whenever one is present, so callers name `"html"` or `"text"` for copied text. This replaces "call `clipboard_inspect` first … prefer `auto`".
- **`.mcpbignore`** lists root-anchored paths for source, scripts, tests, docs, changelog, caches, plugin manifests, and `CLAUDE.md`/`AGENTS.md`, so none ship in the `.mcpb` bundle.
- **`scripts/clean-mcpb.ts` and `scripts/lint-packaging.ts`** anchor the agent-doc matcher at each dependency's package root, so the MCP SDK's `dist/ext/skills/` runtime stays in the bundle ([mcp-ts-core#794](https://github.com/cyanheads/mcp-ts-core/issues/794)); `tests/scripts/bundle-agent-docs.test.ts` pins the boundary. The scripts also strip node-gyp build output and build-only framework files, and `lint:packaging` validates the published `skills/` tree and plugin manifests.
- **Framework sync** refreshes `framework-skills/` (adds `add-skill`), `scripts/`, the bug-report and feature-request issue forms, `.env.example` (request-state key, SSE resumability, log rate limiting, per-signal OTLP endpoints), `bunfig.toml` (`minimumReleaseAge` 3 days → 1 day), and Bun metadata (1.4.4).
- **Docs**: the README restructures Getting started and Running the server and qualifies when image `width`/`height` are present; `docs/design.md` documents `CLIPBOARD_READ_ONLY` and the optional write `content`; the `CLIPBOARD_READ_ONLY` description says `clipboard_write` is listed as disabled in the server manifest.
